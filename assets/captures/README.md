## Consignes

- **Format** : PNG ou JPG, `.png` de préférence pour la netteté du texte
- **Largeur** : 1280 px minimum. Les cartes affichent en 16/10, le haut de l'image
  est la partie visible, donc cadrer sur le contenu utile.
- **Poids** : viser moins de 300 Ko par image. Compresser sur squoosh.app ou
  tinypng.com avant de déposer, sinon la page devient lente sur connexion mobile.
- **Écran à choisir** : le tableau de bord, ou l'écran le plus parlant du métier
  (la caisse pour NopalPro, les bulletins pour Gestion École).
- **Navigateur** : masquer la barre de favoris et les extensions, capturer
  uniquement la zone de la page.

## Confidentialité

Ne jamais publier de capture contenant des données réelles de clients :
noms, numéros de téléphone, montants, adresses. Utiliser les jeux de données
de démonstration fournis par les seeders de chaque application.
